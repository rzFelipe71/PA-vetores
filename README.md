📚 Exercícios de Java — Vetores

Repositório desenvolvido para armazenar exercícios de programação em Java, com foco no aprendizado de lógica de programação e na utilização de vetores.

🎯 Objetivo

Praticar conceitos fundamentais da linguagem Java, como entrada de dados, estruturas de repetição, manipulação de arrays e operações matemáticas.

📝 Exercícios

🔹 Ex003 — Inversão de Vetor

O programa solicita 10 valores inteiros para o vetor A e cria um segundo vetor B com os mesmos valores em ordem inversa. Ao final, exibe os dois vetores.

Conceitos utilizados:

- Vetores (arrays)
- Estruturas de repetição ("for")
- Entrada de dados com "Scanner"
- Acesso aos elementos por índices

🔹 Ex004 — Média dos Valores

O programa solicita 10 valores inteiros, armazena-os em um vetor e calcula a média aritmética dos valores informados.

Conceitos utilizados:

- Vetores (arrays)
- Estruturas de repetição ("for")
- Soma de valores
- Cálculo de média
- Entrada de dados com "Scanner"
